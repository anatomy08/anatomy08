## About Me

I am a Software Engineer and Unity Game Developer from Cavite City, Philippines, with 2.7 years of hands-on experience building 2D, 3D, mobile, and WebGL games using Unity and C#.

My work covers full-cycle game development: gameplay mechanics, UI/UX animation, API integration, asset management, build optimization, debugging, and publishing. Before fully shifting into software and game development, I worked as a licensed Marine Engineer, where I built a strong foundation in analytical thinking, discipline, troubleshooting, and solving problems under pressure.

I enjoy building interactive systems that feel smooth, responsive, and complete, from gameplay logic to release-ready builds.
